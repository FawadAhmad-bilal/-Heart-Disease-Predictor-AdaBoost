# 🫀 Heart Disease Predictor

Predicts heart disease using **AdaBoost** ML model — deployed with **Streamlit**.

**Live app**
https://fawadahmadbilal1.streamlit.app/

## Features
- Predicts heart disease based on patient data
- Confidence score — Disease % vs No Disease %
- Input summary expander

## Tech Stack
`Python` `Scikit-learn` `AdaBoost` `Streamlit` `UCI Dataset`

## Run Locally
```bash
pip install -r requirements.txt
streamlit run heart_app.py
```

## Dataset
UCI Heart Disease Dataset — Cleveland Clinic Foundation (1988)
🔗 https://archive.ics.uci.edu/dataset/45/heart+disease
